# Exercícios de Projeto e Análise de Algoritmos

> Soluções em C para exercícios de divisão e conquista da disciplina de PAA (UFC, 2017.2).

![status](https://img.shields.io/badge/status-concluído-success) ![c](https://img.shields.io/badge/C-99-blue)

## Sobre
Três exercícios da lista da disciplina, todos resolvidos por busca recursiva em tempo logarítmico ou linear:

| Arquivo | Problema |
|---|---|
| `ex14.c` | Encontrar, por bisseção, o elemento que difere entre dois vetores ordenados quase iguais |
| `ex17.c` | Localizar um pico em um vetor (elemento maior que os vizinhos) |
| `ex19.c` | Buscar um valor em matriz com linhas e colunas ordenadas |

`main.c` inclui os três arquivos e contém os dados de teste. O projeto foi criado no Code::Blocks (`PAA 2017.2.cbp`).

## Como executar
```bash
gcc main.c -o paa && ./paa
```
